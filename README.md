# Expense & Budget Visualizer

A mobile-friendly web app for tracking daily spending in Rupiah. Built with HTML, CSS and vanilla JavaScript. Data stays in your browser (Local Storage).

**Live demo:** https://Expense&BudgetVisualizer.github.io/RRepo/

## Features

**Core (MVP)**
- Add an expense with item name, amount, category and date (all fields validated)
- Scrollable transaction list with delete
- Total Balance (budget − spending), updates instantly and turns red when over budget
- Pie chart of spending by category (Chart.js), updates automatically

**Optional challenges**
- Custom categories: add your own (e.g. Bills), each gets its own colour
- Monthly summary: pick a month to see total, number of transactions, top category and a breakdown
- Sorting: newest, oldest, amount high/low, or category A–Z

## Run locally

Open `index.html` in a browser. No install or build step is needed.
